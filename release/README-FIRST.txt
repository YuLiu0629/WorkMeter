⚡ WorkMeter

ChatGPT Work / Codex allowance in your Mac menu bar.

安装 / Install

1. Make sure Codex CLI is installed and signed in:

   codex

   Choose: Sign in with ChatGPT

2. Double-click:

   Install WorkMeter.command

3. Look for ⚡ in the macOS menu bar.

更新 / Update

Download the new version and run the installer again. It replaces the old version.

卸载 / Uninstall

Double-click:

Uninstall WorkMeter.command

隐私 / Privacy

WorkMeter does not need your ChatGPT password, browser cookies, or API key.
It reads allowance information through your locally installed Codex.

WorkMeter 不需要你的 ChatGPT 密码、浏览器 cookie 或 API key。
它通过本机 Codex 获取额度信息。

Not an OpenAI product. Independent open-source project.
不是 OpenAI 官方产品。
